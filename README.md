# Student-Performance-Analysis
This project analyzes student performance, attendance, and test scores using Python, SQL, and Power BI. It helps identify performance trends, compare assessment scores, and understand the relationship between attendance and academic results through data cleaning, analysis, and interactive visualizations.
# Student Performance Analysis

## Project Overview
This project analyzes student academic performance using Excel, SQL, and Power BI. The objective is to understand student scores, compare academic results, and categorize students based on their performance levels.

## Dataset
- 110 student records
- 8 columns
- Student names, test scores, assignment marks, total scores, average scores, and performance levels

## Tools Used
- **Excel:** Dataset preparation and cleaning
- **SQL:** Data analysis and querying
- **Power BI:** Interactive dashboard and data visualization

## Project Workflow
1. Collected the student performance dataset.
2. Prepared the cleaned Excel dataset.
3. Analyzed student scores using SQL queries.
4. Created a Power BI dashboard to visualize key performance indicators and trends.
5. Reviewed the results to identify student performance patterns.

## SQL Analysis
- Total number of students
- Total score analysis
- Students with average scores above a specified threshold
- Excellent-performing students
- Highest and lowest average scores
- Student distribution by performance level
- Highest assignment score
- Performance-level score comparison

## Power BI Dashboard
The dashboard includes:
- KPI cards
- Student score comparison charts
- Performance-level distribution
- Student performance table
- Interactive slicer

## Key Objectives
- Understand academic performance across students.
- Compare assignment and test scores.
- Identify performance categories.
- Present results in an interactive dashboard.

## Data Quality
The dataset requires validation of missing values and test-score fields before final interpretation.

## Conclusion
This project demonstrates practical skills in Excel data preparation, SQL analysis, and Power BI visualization as part of an end-to-end data analytics workflow.
